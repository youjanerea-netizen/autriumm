Atrium · version de revue

Décide ce qu’on garde.

Parcours le contenu de l’application, classe chaque leçon et note ce que tu veux modifier. Tes décisions restent dans ce navigateur et peuvent être exportées.

Comment l’utiliser
  1. Filtre par langage ou recherche un sujet.
  2. Choisis Garder, Modifier ou Retirer pour chaque leçon.
  3. Écris tes remarques : trop long, doublon, exemple à changer, notion manquante…
  4. Exporte tes décisions en JSON pour me les renvoyer et je pourrai appliquer les modifications.

Cette page est un outil de revue séparé : elle ne modifie pas directement les leçons de l’application.

Les décisions sont stockées dans le localStorage de ce navigateur. Exporter le fichier JSON permet de les transmettre et de les restaurer ailleurs.
